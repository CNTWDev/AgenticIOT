# ADR 0011 异步通道与单实例运行

日期：2026-10-02。状态：Accepted for software pilot。补充 ADR 0003 与 ADR 0009；公网性能和生产容量仍待实测。

## 运行模型

WSS、SSE、模型 HTTP 流使用异步 IO。SQLAlchemy 继续同步，在 AnyIO 有界线程中执行短事务；连接池为 5 个常驻加 5 个溢出连接，等待和语句超时为 3 秒。流不持有 ORM Session。服务正文只在请求及有界传输缓冲中流转，不入 PostgreSQL 或 Node SQLite。

Node 的 SQLite 日志由专用单线程独占。虚拟状态和执行结果在该线程事务中提交；外部 Adapter IO 使用有界并发，执行前先持久化 intent。最多同时执行 8 个设备动作、4 个读取，同设备动作串行；全量采样不阻塞命令接收。Adapter 仍须自行保证同设备读写并发安全，首版仅验收虚拟与 MQTT 模拟适配器。

## 会话与容量

- PostgreSQL 保存 NodeSession 的代次、实例、15 秒租约；约每 5 秒重新验机器凭证并续租。资源撤销的在途效果不是瞬时的，不能撤回已发到硬件的指令。
- 单实例内，短数据库扫描寻找持久化待派发命令，再通过 WSS 推送；没有 Node HTTP 领取轮询。扫描间隔目标 100 毫秒，不是延迟保证。
- 两侧控制队列 64 帧、推理数据队列 32 帧，控制优先。推理消费者溢出只中断该调用，不拖住设备回执。Node 推理并发 2，平台进程推理并发 32。
- 推理期限 60 秒、规范化请求 64 KiB、单文本块 16 KiB、输出正文累计 2 MiB。请求解析前另设字节上限。字段及错误语义见运行指南。
- 推理元数据和幂等占位保留 30 天，后台约每分钟清理；期限届满的未结束调用转 unknown。HMAC 使用 SHA-256，存密钥版本摘要；轮换时保留旧密钥覆盖其最后写入后 30 天，最多配置三个旧版本。
- 设备事件按域保留最近 1000 条；同域事务持有游标锁直到提交，防止晚提交的小序号被永久跳过。事件来源只实现 sampled_change。

## 部署与恢复

使用 `python -m agenticiot.serve`，固定单进程，连接并发上限 128。收到停机信号立即拒绝新请求和新派发，最多 5 秒等待已有流及设备回执，再关闭连接；服务器随后给予最多 10 秒结束处理。直接运行通用 uvicorn 开发热更新命令不提供同等预排空保证。

Node 重连恢复的是设备 intent、原命令 ID 和待上传证据，不是模型输入或生成输出。被拒绝的上传保留在本地诊断隔离表，不阻塞后续记录。未知设备动作暂停该绑定的后续派发；目前没有自动清除这类隔离的管理操作。

旧 HTTP Edge 路由只在后端历史回归测试显式装配，默认应用和实际 OpenAPI 不挂载。旧运行器代码中的日志实现复用于新 Node，不意味着提供两个生产派发通道。

多实例未实现。未来倾向通过 NodeSession 查找持有连接的实例，再做内部鉴权的流式 HTTP 转发；LISTEN/NOTIFY 可仅承担持久化记录的唤醒，不运送正文。不能仅修改 workers 数量或添加 Redis 宣称扩容完成。

## 验证范围

自动化覆盖单机真实 WebSocket、模拟模型 SSE、虚拟灯具、真实 MQTT 传输到模拟设备、权限撤销、旧代次拒绝、日志恢复和并发调度。它不能验证 Ollama 的具体版本/模型、家庭 NAT/Wi-Fi、云中转预算、真实硬件或生产安全运维。
