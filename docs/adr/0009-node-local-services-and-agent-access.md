# ADR 0009 Node 本地服务与 Agent 接入

日期：2026-10-02。状态：边界与行为规则 Accepted；性能和兼容性 Pending validation。

本文依据用户确认的评审共识修订 [ADR 0008](0008-device-and-ai-service-platform.md)，不改写其历史原文。当前架构正文为 [v0.3](../architecture/device-node-services-v0.3.md)。同时补充 ADR 0003 的长连接并发模型，保留 ADR 0007 的真实硬件门禁。

## 已接受的边界

- 保留 Access、Nodes、Devices 和收窄后的 AI Services，采用模块化单体和 PostgreSQL。
- 首版 AI Services 只经 Node 访问获准本地服务；云模型由入口或 Agent Runtime 中的确定性策略代码按产品授权处理，不经过本平台。
- 推理采用一次 POST 内的异步流式 IO，不持久化正文、不排队恢复；设备命令维持异步持久化与回执。
- 域使用平台生成的内部 ID，外部别名与平台授权分开；入口可在授权上限内自助管理资源。
- 薄工具或 MCP 层负责查询与执行，平台可靠传递已摄取的设备事件，入口或 Agent Runtime 消费后决定唤醒。
- WSS 替换当前未部署生产的轮询方案；同步数据库访问可在有界线程执行短事务，长连接不占用阻塞线程或数据库事务。

## 可测试的规则

以正文 R1–R8 为规范，重点验收以下内容：

1. 有效权限为令牌、当前平台 Grant、资源约束的交集；别名不自行授予权限，域内管理不允许自我提权。
2. 所有命令需要幂等键。非幂等或未知动作另需可信 turn_ref 与稳定 operation_ref；操作身份与参数指纹分开，同身份不同内容冲突。同轮有意重复操作有不同 operation_ref，重试不重新分配。deadline 不保证消除迟到覆盖。
3. 命令接收不等全量状态读取，跨设备有界并发、同设备副作用动作有序；适配器和日志并发安全必须验收。
4. 采样推导事件与设备原生事件分开标注，声明缺口与时间精度；游标保证已摄取事件可恢复，不承诺采集不到的物理事件。
5. 推理幂等键可选，有键只防重复派发，不重放结果；用带密钥指纹，首版单次派发、无备用。unknown 对调用方终结，迟到事实追加审计。
6. 本地性显示为审批声明，不把白名单或本地地址当作已验证的宿主机出口隔离。严格本地数据请求在云中转首版拒绝。
7. Node 会话租约从第一天持久化代次、实例和期限；数据库不存连接对象。停机先拒绝新工作、限时排空，证据允许重连补报。
8. LISTEN/NOTIFY 仅作为可选唤醒，持久化记录可补查。多实例未来优先评估按会话租约内部流式转发；通知不传 token，不宣称首版已支持扩容。

## 明确不做的能力

云提供方接入、路由与备用、计费网关、GPU 管理、推理正文留存与结果重放、后台推理恢复、通用工作流、云边双主、离线授权、多实例生产运行和长期双传输兼容均不在首版。域管理首步只做权限、迁移和最小 API，不做入网向导。

## 待验证的技术选择

Chat Completions 严格子集作为外部兼容方向，字段和流中断行为需以选定 Node 服务进行契约测试。真实云与家庭网络下的时延、背压、并发和部署排空需要实验；不能用模拟器证明物理设备能力。

[实验计划](../experiments/node-relay-validation.md)列出实验前预算及复现条件。预算是待运行前确认的工程门槛，不是用户已签署的 SLA 或实测结果。实现顺序以[实施计划](../architecture/implementation-plan.md)为准。

## 替代范围与历史

本决策取代 ADR 0008 中首版云连接与备用、推理持久化队列及正文恢复要求，并收窄产品定位；不删除 0008，亦不追溯修改其 Accepted 记录。设备授权、证据、unknown 不盲目重发和模块化单体原则继续成立。

两轮评审补足了稳定操作身份、事件采集来源、入口授权上限、宿主机出口声明和运行模型。与评审中简写不同，同一 turn 内的重复动作仍需 operation_ref 区分；租约与非对称签名都不等于已具备无损多实例或离线控制。
