# Capability API — draft reference

> Generated by `uv run python scripts/contracts.py`. Do not edit manually.
> Design contract status. Execution supports virtual and MQTT-demo lights only.
> Fresh reads and body-supplied context are unsupported.
> See docs/api/node-local-services.md for implemented authorization and streaming.
> Implemented endpoints are in `api/platform.openapi.json` and runtime `/docs`.

Base path: `/v1`

| Method | Path | Purpose | Status |
|---|---|---|---|
| GET | `/things` | Discover authorized things | Implemented |
| GET | `/things/{thingId}` | Get a canonical Thing description | Implemented |
| GET | `/things/{thingId}/state` | Read the latest authorized state projection | Implemented |
| POST | `/things/{thingId}/actions/{actionName}` | Request a durable asynchronous physical action | Implemented |
| GET | `/commands/{commandId}` | Get command status and available receipts | Implemented |
| GET | `/commands/{commandId}/receipts` | List immutable execution receipts | Implemented |
| GET | `/events` | Subscribe to authorized events using Server-Sent Events | Implemented |
