# 首版软件交付验证记录

日期：2026-10-02。结论：软件闭环可用于本地试用和集成开发，尚不满足真实模型、家庭网络、硬件或生产上线验收。

## 已通过

- 72 项后端测试，在专用 PostgreSQL 上运行，包含 26 项数据库/链路集成测试。
- 14 项 Playwright 测试，覆盖桌面与手机端的设备注册、WSS Node、虚拟灯具、MQTT 模拟灯具、管理凭证与服务审批。实际启动后端和 Node 子进程，不以业务 API mock 代替执行链路。
- `make check`：Python lint/格式、非数据库测试、计划与实际 OpenAPI 验证、快照一致性、前端 lint/格式、TypeScript 和生产构建。
- `alembic check` 无 ORM 与迁移漂移；当前 head 为 `0010_hmac_key_version`。
- 旧版本隔离 Schema 中的回填测试保留设备 ID、型号关联、版本和外部域别名；跨越内部域迁移的有损自动降级被拒绝。显式认领旧 Edge 保留节点 ID 和绑定。
- 签名入口权限取交集、跨域拒绝、撤销不能被重复引导恢复、Node 与用户凭证分离、旧会话代次拒绝。
- 推理文本流经真实本机 WebSocket 往返，使用模拟 SSE 上游；验证正文不入调用元数据、同键不重派发、HMAC 轮换后仍识别旧键、撤销中断、unknown 终态和迟到事实。
- 7 条突发命令经实际 WebSocket 完成；另以 13 个各阻塞 300 毫秒的模拟读取证明动作不等待采样完成。后者是快速回归，不是计划中真实网络的 2 秒离线读取负载测量。
- 采样变化事件可分页及用 Last-Event-ID 经 SSE 恢复；仍不代表完整物理事件历史。后台手机截图已检查，无页面级横向溢出。

## 使用边界

先按[运行指南](../api/node-local-services.md)显式引导账号授权并登记 Node。账号登录流程由产品入口提供；平台只管理资源域、授权、机器身份和服务目录。

下一验收需要选定一个可运行的文本生成模型、获准的云/家庭网络拓扑和真实设备目标。继续沿用[云中转实验计划](node-relay-validation.md)的预先预算，不用本机回归时长替换公网指标。软件测试通过不将这些门禁自动标记为完成。
